PUBLICAR NO GITHUB PAGES
1. Extraia o ZIP.
2. Envie TODOS os arquivos da pasta extraída diretamente para a raiz do repositório premiumclean. Não é necessário criar pasta assets.
3. Substitua index.html. Os novos estilos e scripts têm nomes pc-styles.css e pc-script.js para evitar conflito com a versão anterior.
4. Em Settings > Pages, use main / root.
5. Aguarde o deploy concluir. Recarregue com Ctrl+F5.

O site não foi publicado por nós. Você controla a publicação.

MÍDIAS PROVISÓRIAS
As imagens são geradas para visualização do projeto. Os comparadores usam demonstrações geradas, não resultados reais. Os MP4 são prévias animadas de imagens estáticas, não filmagens de execução. Substitua por material real antes de anunciar. Os depoimentos estão claramente identificados como fictícios e os indicadores de experiência são ilustrativos até confirmação. Não foi inventada nota ou quantidade de avaliações do Google.

SUBSTITUIR MÍDIAS
Mantenha os nomes dos arquivos para trocar as imagens sem editar HTML. Comparações pc-antes-depois-*.webp são diptychs: antes à esquerda, depois à direita, com metade do arquivo para cada imagem e enquadramento idêntico. Antes de usar vídeos reais, otimize tamanho, duração e versão móvel. pc-hero.mp4 = fundo/animação de higienização; pc-protecao.mp4 = demonstração de proteção. Capas permanecem visíveis quando há economia de dados ou preferência por movimento reduzido.

CONFIGURAÇÃO
WhatsApp e mensagens ficam no início de pc-script.js. Os links possuem destino funcional mesmo sem JavaScript. Não há anúncios, analytics ou pixels instalados. Um evento JavaScript premiumclean:whatsapp é emitido ao clicar, mas nenhuma ferramenta coleta dados por padrão. Cliques não representam conversas ou vendas.
Canonical, Open Graph, JSON-LD, sitemap e URLs usam https://lorensatto.github.io/premiumclean/. Ao conectar domínio próprio, substitua essa base nos arquivos HTML e no sitemap.xml/robots.txt. O robots.txt só é lido pelo Google na raiz do domínio; no GitHub Pages de projeto, envie o sitemap diretamente ao Search Console.

PÁGINAS
Inicial; sofá; impermeabilização; colchões; cadeiras e poltronas; tapetes; cortinas; ar-condicionado; privacidade; 404.

DESIGN E ACESSIBILIDADE
Faixas compactas, navegação móvel, comparadores por arraste/teclado, perguntas expansíveis, modal de vídeo com Escape, suporte a movimento reduzido, fonte local e imagens WebP.

A fonte e as mídias ficam no próprio pacote. Apenas o mapa depende de carregamento externo. Sem build, servidor ou dependências para publicar.

No celular, a hero mostra uma foto responsiva e a prévia animada é iniciada ao tocar no controle. No desktop, toca automaticamente quando permitido. Os vídeos são pausados fora da área visível.
